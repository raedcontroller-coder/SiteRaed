# Raed | Future Intelligence

A **Raed** é uma boutique de desenvolvimento de software focada em agilidade, qualidade e entrega de valor real através de soluções de Software e Inteligência Artificial.

## 🚀 O Projeto

Este repositório contém o site institucional da Raed, desenvolvido com uma estética *High-End Tech*, focada em proporcionar uma experiência imersiva e moderna para clientes que buscam soluções tecnológicas de elite.

### 🛠️ Tecnologias Utilizadas

*   **Frontend:** HTML5, CSS3 (Modern UI/UX)
*   **Interatividade:** JavaScript Vanilla
*   **3D:** Google Model Viewer (Renderização de modelos `.glb`)
*   **Efeitos Visuais:** HTML5 Canvas (Partículas interativas)
*   **Ícones:** Phosphor Icons
*   **Integração:** Web3Forms (Processamento de formulários sem backend)

## 📁 Estrutura do Projeto

A organização do diretório segue as melhores práticas para sites estáticos:

```text
/
├── assets/
│   ├── img/        # Logos e ativos visuais
│   └── models/     # Modelos 3D (ex: astronaut.glb)
├── css/            # Estilização (Zinc-based dark theme)
├── js/             # Lógica de interface e animações
├── old/            # Backups e versões anteriores
├── index.html      # Página principal institucional
└── mvp.html        # Landing page para o produto Sprint MVP
```

## ✨ Funcionalidades

*   **Hero Interativa:** Título com gradiente dinâmico e modelo 3D de astronauta que reagem ao movimento do mouse.
*   **Fundo de Partículas:** Animação de rede neural em tempo real via Canvas.
*   **Formulários Funcionais:** Integração direta com e-mail via API do Web3Forms.
*   **Sprint Raed (MVP):** Página dedicada para oferta de prototipagem funcional de baixo investimento (R$ 1.990).
*   **Design Responsivo:** Interface adaptável para dispositivos móveis e desktops.

## 💻 Como Rodar

Como o projeto é um site estático, não há necessidade de compilação:

1.  Clone o repositório.
2.  Abra o arquivo `index.html` em qualquer navegador moderno.
3.  Para testar o formulário, certifique-se de estar rodando em um ambiente de servidor (mesmo que local, como a extensão *Live Server* do VS Code) para que as requisições `fetch` funcionem corretamente.
